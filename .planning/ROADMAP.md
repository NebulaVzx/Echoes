## 计划中

### 📋 v1.1 Echo Assistant

**目标：** 对话式 AI 助手，基于 RAG 回答用户记忆相关问题

**关键交付物：**
- Chat UI 侧边栏
- RAG 检索逻辑（语义搜索 + LLM 生成）
- 引用来源展示
- 对话历史管理

**验证标准：** "我上周存的关于 Go 的文章有哪些？" → 列出相关记忆 + 总结回答
