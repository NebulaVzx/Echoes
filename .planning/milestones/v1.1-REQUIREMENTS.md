# 需求规格 (v1.1) — ARCHIVED

## 1. Echo Assistant (P0) — ALL COMPLETE

### 1.1 对话界面
- [x] **CHAT-01** 用户在首页可打开/关闭 Chat 侧边栏
- [x] **CHAT-02** 侧边栏显示对话历史列表，支持新建对话
- [x] **CHAT-03** 对话界面显示用户和 AI 消息，支持 Markdown 渲染
- [x] **CHAT-04** 发送消息后显示加载状态
- [x] **CHAT-05** 支持暗黑模式

### 1.2 RAG 检索
- [x] **CHAT-06** 用户提问后，系统先通过语义搜索检索相关记忆
- [x] **CHAT-07** 检索结果按相似度排序，取 Top N（默认 5 条）
- [x] **CHAT-08** 检索不到相关记忆时，AI 明确告知

### 1.3 LLM 回答生成
- [x] **CHAT-09** 使用现有 LLM Provider 抽象层生成回答
- [x] **CHAT-10** Prompt 包含检索到的记忆内容作为上下文
- [x] **CHAT-11** 回答中引用来源（显示引用标注 [1] [2]）
- [x] **CHAT-12** 支持多轮对话（上下文保留最近 10 轮）

### 1.4 对话历史
- [x] **CHAT-13** 对话记录持久化到数据库
- [x] **CHAT-14** 用户可查看历史对话列表并切换
- [x] **CHAT-15** 用户可删除单条对话

## 2. Bug 修复 (P1) — ALL COMPLETE

### 2.1 OAuth State 清理
- [x] **BUG-01** OAuth state map 添加 TTL 机制（10 分钟过期）
- [x] **BUG-02** 启动定期清理 goroutine（每 5 分钟扫描）

### 2.2 Gateway 健康检查

- [x] **BUG-05** 反向代理增加连接超时配置

### 2.3 前端分页 UI

- [x] **BUG-07** 分页组件支持移动端（简洁页码）
- [x] **BUG-08** 切换页码时平滑滚动到顶部
