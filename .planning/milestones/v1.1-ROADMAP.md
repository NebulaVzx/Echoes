## Milestone Summary

**Key Decisions:**
- D-06-04-01: ReactMarkdown v9 不支持 className prop，采用 div 包裹方案
- D-06-04-02: 所有 Chat 组件为纯展示组件，数据通过 props/callbacks 传递
- D-07-01: OAuth state 使用 map + goroutine 清理（单机部署足够，Redis 过度设计）
- D-07-02: Gateway 健康检查采用聚合式下游探测（微服务网关标准做法）
- D-07-03: 双模式分页（默认加载更多 + Settings 可切页码）
- D-07-04: Service 层 + Mock Repository 的 Go 测试策略

**Issues Resolved:**
- OAuth state 内存泄漏（10min TTL + 5min 清理 goroutine）
- Gateway 缺少健康检查端点（新增聚合 /health）
- 路径遍历绕过公开路由（CR-02，filepath.Clean → stdpath.Clean）
- Chat 系统提示重复插入（WR-01）
- json.Marshal(citations) 静默失败（WR-02）
- 未使用 isNewConversation 变量（IN-01）
- 前端分页体验（默认加载更多 + 可选页码组件）

**Issues Deferred:**
- Redis TTL for OAuth state（多实例时考虑）
- testcontainers 集成测试（后续阶段）
- 熔断器模式（后续 milestone）
- Chat 消息流式输出（SSE）
- 对话导出（Markdown / PDF）

**Technical Debt:**
- Windows filepath.Clean 兼容性问题（已修复为 stdpath.Clean）
- Playwright E2E 需要完整 Docker 栈运行（当前环境未常驻全栈）
- Gateway 镜像缺少 volume mount（已补充）
