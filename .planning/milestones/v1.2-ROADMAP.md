## Overview

v1.2 "记忆的温度" 将 Echoes 从"存储工具"升级为"记忆伴侣"。通过 AI 陪伴建议、标签重生和情感化功能，让每一次保存记忆都充满温度。

**Slogan:** "不只是存储，更是陪伴"

## Phases

### Phase 8: AI 陪伴建议

**Goal:** 保存记忆后异步生成温情/建设性的 AI 反馈建议，持久化保存并与记忆关联。用户可选择开启/关闭此功能（默认关闭）。
**Depends on:** —
**Plans:** 5 plans

Plans:

- [x] 08-01: Database Schema (ai_suggestions 表) + Go/TS 类型定义
- [x] 08-02: Memory Service 建议层 (Repository + Service + Handler + Redis Stream)
- [x] 08-03: Processor Service 建议消费者 (Consumer + Prompts + LLM 扩展)
- [x] 08-04: 前端创建表单 + 设置页 (AI 开关、建议卡片、风格配置)
- [x] 08-05: 前端记忆卡片 + 详情页 (✨ 标记、建议展示、反馈)

**Details:**
- 独立 `ai_suggestions` 表，ON DELETE CASCADE
- 三种建议风格：温柔型 / 实用型 / 启发型
- 文字/链接内容采用不同提示策略（情绪支持、知识拓展、行动建议等）
- 失败不阻塞保存，指数退避重试
- 前端 Sparkles 图标 hover 展开，详情页完整展示 + 反馈按钮

### Phase 9: 标签重生

**Goal:** 标签从静态附属品升级为可过滤、可管理、可发现的知识节点。
**Depends on:** Phase 8
**Plans:** 4 plans

Plans:

- [x] 09-01: 数据库 Schema + User Settings 扩展（标签颜色、分类）
- [x] 09-02: 后端标签 API（标签列表、关联标签、合并、多标签过滤）
- [x] 09-03: 前端标签过滤器集成（首页标签栏、多选 AND 过滤、标签颜色）
- [x] 09-04: 前端标签管理页（/tags — 云图/卡片/列表视图、颜色选择器、合并、自动分类）

**Details:**
- 标签颜色按用户存储在 `users.settings` JSONB 中
- 多标签过滤使用 PostgreSQL `@>` 数组包含操作符
- 标签合并原子 UPDATE，关联标签基于共现统计
- 标签管理页支持三种视图 + LLM 自动分类

### Phase 10: 记忆的温度

**Goal:** 通过 Streaks、那年今日、时间胶囊、每日回顾，让记忆有情感价值。
**Depends on:** Phase 9
**Plans:** 4 plans

Plans:

- [x] 10-01: 数据库 Schema + Streaks & Daily Stats APIs（Wave 1 后端）
- [x] 10-02: Time Capsule Backend APIs（Wave 1 后端）
- [x] 10-03: Frontend Warmth Cards（Wave 2 前端）
- [x] 10-04: Frontend Time Capsule Integration（Wave 2 前端）

**Details:**
- **Streaks**: 连续记录天数统计，创建表单下方显示状态（支持 1 天容错）
- **那年今日**: 首页顶部展示一年前的记忆，无数据时选随机高价值旧记忆
- **时间胶囊**: 保存时可选择 7/30/100 天封印，到期首页显示解锁仪式卡片
- **每日回顾**: 可折叠卡片展示今日保存数量、主题标签、值得回顾的旧记忆
- 温暖功能全部使用 violet/amber 配色， subtle 融入现有设计

## Milestone Summary

**Key Decisions:**

- AI 建议默认关闭，用户主动选择才展开（不打扰原则）
- 建议生成失败不阻塞保存流程，异步重试（陪伴感 > 功能性）
- 标签颜色按用户个性化存储，非全局预设
- 时间胶囊封印期间记忆不显示在时间轴，保持专注
- Streak 统计支持 1 天容错（grace period），减少焦虑

**Issues Resolved:**

- Docker Next.js 构建缓存冲突（.next/ 目录 volume mount 问题）
- Gin 路由顺序：特定路由必须在参数化路由之前注册
- Zod v4 + @hookform/resolvers v5 表单验证兼容性
- bool + omitempty 导致 false 值被跳过的问题

**Issues Deferred:**

- 标签关联网络图（轻量版）— 当前仅显示相关标签列表
- 时间胶囊自定义日期选择器的移动端体验优化
- Streak 徽章系统（7/30/100 天 subtle 徽章）— 基础统计已做，徽章 UI 待细化

**Technical Debt Incurred:**

- `/tags` 页面所有视图集中在单个文件（组件树较浅，未来可拆分）
- 标签分类视图偏好未持久化（每次刷新重置为云图）
- 时间胶囊解锁仪式卡片动画可进一步丰富
