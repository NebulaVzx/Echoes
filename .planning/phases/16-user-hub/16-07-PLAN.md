# Plan 16-07: /settings 调整

## 目标

1. 移除 Section 0 记忆统计（迁移到 /profile）
2. 新增隐私与数据 Section
3. 新增账户安全 Section
4. 调整现有 Section 顺序

## 任务清单

### 1. 从 /settings 移除记忆统计

删除 web/app/(main)/settings/page.tsx 中的：
- streakData state 和 useEffect
- Flame, Trophy import
- 记忆统计展示区域

### 2. 调整 Section 顺序

新顺序：
1. LLM 连接
2. 处理偏好
3. 搜索偏好
4. 界面偏好
5. AI 建议
6. 隐私与数据（新增）
7. 账户安全（新增）

### 3. 新增隐私与数据 Section

内容：
- 隐私开关组（Switch 组件）：
  - 允许记忆参与 AI 训练分析（default: false）
  - 开启情绪分析（default: true）
  - 自动删除 N 天前的记忆（Switch + Number Input，default: null）

- 数据导出：
  - 格式选择：两个水平卡片（Markdown / JSON）
  - 单选样式：border + 选中时 amber 边框 + 勾选图标
  - 导出数据 按钮（主按钮）
  - 加载状态：生成中...
  - 导出成功后自动下载文件

- 调用 API：
  - updatePrivacySettings
  - exportData

### 4. 新增账户安全 Section

内容：
- 头像上传（复用 AvatarUpload 组件）
- 用户名修改（inline input + 保存）
- 密码修改（旧密码 + 新密码 + 确认密码）
  - 表单验证：新密码最小 8 位
  - 确认密码必须匹配
- 邮箱变更（当前邮箱只读 + 新邮箱 + 验证按钮）
  - P1 简化：仅保存新邮箱，不发验证邮件
- TOTP 双因素认证（Switch + 扫码区域）
  - P1 实现
- 活跃会话列表（设备 + 时间 + 退出按钮）
  - 调用 listSessions / revokeSession API
- 注销账户（红色区域，Collapsible 面板）
  - 需二次确认：输入确认注销
  - 密码验证
  - 软删除按钮 + 硬删除按钮（红色 outline）

### 5. 表单状态管理

新增 state：
- privacySettings
- accountSecurity form
- sessions list

新增保存状态：
- isSavingPrivacy
- isSavingSecurity

### 6. 扩展 settingsSchema

新增字段验证：
- privacy_allow_ai_training: boolean
- privacy_enable_emotion_analysis: boolean
- privacy_auto_delete_days: number | null

## 验收标准

- [ ] 记忆统计已从 /settings 移除
- [ ] 隐私开关可正确切换和保存
- [ ] 数据导出可选择格式并下载
- [ ] 密码修改需旧密码验证
- [ ] 注销账户需二次确认和密码验证
- [ ] 活跃会话列表可显示和踢出
- [ ] 所有新增表单有正确验证

## 风险与缓解

| 风险 | 缓解 |
|------|------|
| settings 页面过长 | Collapsible 折叠面板 |
| 注销误操作 | 二次确认 + 密码验证 |
| 隐私设置与现有功能冲突 | 设置即时生效，后端校验 |
