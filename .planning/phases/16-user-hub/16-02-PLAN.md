# Plan 16-02: DNA Consumer + 人格 Prompt 模板 + LLM 注入点

## 目标

1. 实现 dna:generate Redis Stream 消费者，分析用户全部记忆生成 DNA 报告
2. 创建 4 种 AI 人格的 Prompt 模板文件
3. 在 LLM Provider 工厂中注入人格 system prompt 前缀
4. 确保人格切换影响所有 AI 交互

## 任务清单

### 1. 创建人格 Prompt 模板 services/processor-service/app/personas/

文件列表：
- gentle_senior.txt -- 温柔学姐
- minimalist.txt -- 极简主义者
- curious.txt -- 好奇探索者
- old_friend.txt -- 老朋友

### 2. 创建人格加载器 services/processor-service/app/personas/__init__.py

PersonaLoader 类，支持按名称加载模板，缓存已加载内容。

### 3. 扩展 LLMFactory 注入人格 services/processor-service/app/services/llm/factory.py

修改 LLMFactory.create()：
- 新增参数 persona: str = None
- 当 persona 不为空时，加载对应模板并注入为 system prompt 前缀

### 4. 扩展 Base LLM Provider services/processor-service/app/services/llm/base.py

新增 set_persona() 方法，在 complete/chat 调用前拼接 persona prompt。

### 5. 创建 DNA Consumer services/processor-service/app/consumers/dna_consumer.py

继承 RedisStreamConsumer：
- Stream: dna:generate
- process_message 流程：
  1. 获取 user_id
  2. 分页获取用户全部记忆
  3. 统计计算（领域分布、阅读偏好、记录节奏、标签演化、记忆影响力）
  4. 调用 LLM 生成 AI 洞察语
  5. 写入 user_insights 表
  6. 报告任务状态

### 6. 在 services/processor-service/app/main.py 注册 DNA Consumer

### 7. 修改现有消费者使用人格注入

修改 _create_llm() 函数，从 fields 读取 echo_persona 并传递。

## 验收标准

- [ ] 4 个人格模板文件存在且内容完整
- [ ] PersonaLoader 可正确加载模板
- [ ] LLMFactory.create(persona=...) 带有人格前缀
- [ ] DNA Consumer 可正确继承 RedisStreamConsumer
- [ ] DNA Consumer 统计计算输出合理
- [ ] 所有现有消费者支持人格注入
