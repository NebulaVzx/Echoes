# Plan 16-03: User Service API 扩展

## 目标

为账户基础功能提供完整的后端 API：
1. 头像上传（复用 MinIO，路径 avatars/{user_id}.jpg）
2. 用户名修改
3. 密码修改（需旧密码验证）
4. 邮箱变更（发送验证流程，P1 简化版）
5. 账户注销（软删除 + 硬删除）
6. 活跃会话列表与踢出
7. TOTP 双因素认证（P1）

## 任务清单

### 1. 扩展 services/user-service/internal/domain/user.go

新增 Request 类型：
- UploadAvatarRequest
- UpdateUsernameRequest
- ChangePasswordRequest（old_password, new_password）
- DeactivateAccountRequest（确认密码）
- ListSessionsResponse
- RevokeSessionRequest

### 2. 扩展 AuthService services/user-service/internal/service/auth_service.go

新增方法：
- UpdateUsername(ctx, userID, username) error
- ChangePassword(ctx, userID, oldPassword, newPassword) error
- UploadAvatar(ctx, userID, fileData) (url string, error)
- DeactivateAccount(ctx, userID, password) error -- 软删除
- HardDeleteAccount(ctx, userID, password) error -- 硬删除
- ListSessions(ctx, userID) ([]UserSession, error)
- RevokeSession(ctx, userID, sessionID) error
- GenerateTOTPSecret(ctx, userID) (qrURL string, error) -- P1
- VerifyTOTP(ctx, userID, code) (bool, error) -- P1

### 3. 扩展 AuthHandler services/user-service/internal/transport/auth_handler.go

新增路由（在 protected 组内）：
- PUT /me/username
- PUT /me/password
- POST /me/avatar
- DELETE /me/account
- DELETE /me/account/hard
- GET /me/sessions
- DELETE /me/sessions/:id
- POST /me/totp/enable -- P1
- POST /me/totp/verify -- P1

### 4. 实现头像上传逻辑

- 接收 multipart form-data
- 文件大小限制 5MB
- 格式限制：jpg, png, webp
- 调用 MinIO Client 上传至 avatars/{user_id}.jpg
- 更新 users.avatar_url
- 返回公开访问 URL

### 5. 实现密码修改逻辑

- 验证旧密码（bcrypt compare）
- 新密码 bcrypt hash（cost=12）
- 更新 users.password_hash

### 6. 实现账户注销逻辑

软删除：
- 验证密码
- 设置 is_active = false
- 保留 30 天数据

硬删除：
- 验证密码
- 删除用户所有数据（级联删除 memories, user_insights 等）
- 从 MinIO 删除头像

### 7. 实现活跃会话管理

- JWT token 解析时记录会话信息
- ListSessions 返回当前用户的活跃会话
- RevokeSession 设置 is_revoked = true

## 验收标准

- [ ] 头像上传 API 可接收图片并返回 URL
- [ ] 用户名修改即时生效
- [ ] 密码修改需旧密码验证
- [ ] 软删除后用户无法登录
- [ ] 硬删除彻底清除用户数据
- [ ] 活跃会话列表可显示设备信息
- [ ] 可踢出指定会话
- [ ] 所有新增 API 有正确错误码返回

## 风险与缓解

| 风险 | 缓解 |
|------|------|
| 头像上传文件过大导致内存问题 | 5MB 限制，流式上传到 MinIO |
| 硬删除误操作 | 需二次确认 + 密码验证 |
| 会话信息伪造 | 结合 JWT 验证 |
