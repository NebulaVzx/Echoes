# Plan 16-06: AI 人格选择 + 学习路径 + 数据仪表盘

## 目标

1. AI 人格选择 Tab：4 个人格卡片 + 预览效果
2. 学习路径 Tab：知识地图 + 推荐路径列表
3. 数据仪表盘 Tab：统计卡片 + 存储占用 + AI 调用统计

## 任务清单

### 1. 创建 PersonaSelector 组件

- 4 个人格卡片，2x2 网格（桌面）/ 单列（移动端）
- 每个卡片：emoji(24px) + 名称(14px bold) + 描述(12px gray)
- 选中状态：amber 边框 + bg-amber-50
- 数据：
  - gentle_senior: 温柔学姐 / 语气温暖、鼓励为主
  - minimalist: 极简主义者 / 不说废话、bullet points
  - curious: 好奇探索者 / 不停追问、引导深入思考
  - old_friend: 老朋友 / 像认识多年的朋友、会引用你的记忆

- 底部：预览效果 按钮
  - 点击弹出 Dialog
  - 内嵌模拟对话气泡
  - 使用当前选中人格生成示例回复

### 2. 创建 PersonaPreviewDialog 组件

- 模拟用户发送一条记忆
- AI 用选中人格回复
- 调用 suggestion API 但带 persona 参数

### 3. 创建 LearningPath 组件

知识地图：
- 复用 ConstellationGraph 组件（从 /explore 导入）
- 节点 = 知识领域（技术/生活/艺术/商业/科学）
- 节点大小 = 该领域记忆数量
- 边 = 领域间关联

推荐路径列表：
- 基于用户已有标签，推荐下一步学习方向
- 每个路径：标题 + 描述 + 标记为学习中 按钮
- 数据来自 /dna API 的 learning_paths 字段（P1）

### 4. 创建 DataDashboard 组件

3 列统计卡片（桌面），全宽堆叠（移动端）：
- 总记忆数（react-countup 动画）
- 总字数（react-countup 动画）
- 覆盖主题数（react-countup 动画）

存储占用：
- Progress 组件显示 MinIO 使用量 / 限额
- 限额暂定 1GB

AI 调用统计：
- 本月 tokens 用量（BarChart）
- 数据来自 /dna/stats API

### 5. 人格设置保存

- 选中人格后调用 UpdateSettings API
- 保存 echo_persona 到 users.settings
- Toast 提示：AI 助手已切换为 [人格名]，下次交互时生效

## 验收标准

- [ ] 4 个人格卡片展示正确，选中状态明显
- [ ] 预览效果弹出模拟对话
- [ ] 知识地图复用 ConstellationGraph 正确显示
- [ ] 推荐路径列表可交互
- [ ] 3 个统计数字有 countup 动画
- [ ] 存储进度条显示正确
- [ ] AI 调用统计图表正确
- [ ] 人格切换后设置保存成功

## 风险与缓解

| 风险 | 缓解 |
|------|------|
| ConstellationGraph 复用需要适配新数据格式 | 包装一层数据转换组件 |
| 预览效果需要真实 LLM 调用 | 使用缓存的示例回复或简化调用 |
| countup 动画性能 | 只在视口内触发 |
