# Plan 16-04: Memory Service API 扩展

## 目标

1. DNA 数据查询 API（GET /dna）
2. 记忆统计聚合 API（GET /stats）
3. 数据导出端点（GET /export）
4. 人格设置传播到 processor

## 任务清单

### 1. 扩展 MemoryRepository services/memory-service/internal/repository/memory_repository.go

新增接口方法：
- GetUserDNAStats(ctx, userID) (*domain.UserDNA, error) -- 聚合统计
- GetKnowledgeAreaDistribution(ctx, userID) (map[string]float64, error)
- GetReadingPreferences(ctx, userID) (*domain.ReadingPreference, error)
- GetRecordingRhythm(ctx, userID) (*domain.RecordingRhythm, error)
- GetTagEvolution(ctx, userID, weeks int) ([]domain.TagEvolution, error)
- GetMemoryInfluence(ctx, userID, limit int) ([]domain.MemoryInfluence, error)
- CountTotalWords(ctx, userID) (int64, error)
- GetUniqueTags(ctx, userID) ([]string, error)

### 2. 创建 DNA Handler services/memory-service/internal/transport/dna_handler.go

端点：
- GET /api/v1/dna -- 获取用户最新 DNA 报告
  - 查询 user_insights 表最新记录
  - 如无记录且记忆数 >= 10，触发 dna:generate 队列
  - 返回完整 DNA 数据

- GET /api/v1/dna/stats -- 实时统计（用于数据仪表盘）
  - 总记忆数、总字数、覆盖主题数
  - 存储占用（MinIO 统计）

- POST /api/v1/dna/refresh -- 手动刷新 DNA
  - 检查冷却时间（1 小时）
  - 发布 dna:generate 到 Redis Stream

### 3. 创建 Export Handler services/memory-service/internal/transport/export_handler.go

端点：
- GET /api/v1/export?format=markdown|json
  - < 1000 条：同步生成，直接返回
  - >= 1000 条：异步生成，返回任务 ID，前端轮询

Markdown 格式：
每条记忆一个文件，frontmatter 包含标签/来源/创建时间
可选按标签分文件夹

JSON 格式：
完整数据结构，包含所有字段

### 4. 扩展 Memory Handler 传播人格

在创建记忆时，从 user-service 获取用户设置中的 echo_persona
将 echo_persona 写入 Redis Stream message fields

### 5. 扩展 Gateway 路由 services/gateway/cmd/main.go

新增路由：
- GET /api/v1/dna -> memory-service
- GET /api/v1/dna/stats -> memory-service
- POST /api/v1/dna/refresh -> memory-service
- GET /api/v1/export -> memory-service

## 验收标准

- [ ] GET /dna 返回最新 DNA 报告或触发生成
- [ ] GET /dna/stats 返回实时统计数据
- [ ] POST /dna/refresh 正确发布队列消息
- [ ] 导出 < 1000 条记忆可直接下载
- [ ] 导出 >= 1000 条返回任务 ID 可轮询
- [ ] Markdown 导出含正确 frontmatter
- [ ] 人格设置从 user-service 传播到 processor

## 风险与缓解

| 风险 | 缓解 |
|------|------|
| DNA 统计大数据量查询慢 | 数据库索引 + 分页 |
| 导出大数据量阻塞 | 异步生成 + MinIO 存储 |
| 人格传播链路断裂 | 默认值回退（不注入人格） |
