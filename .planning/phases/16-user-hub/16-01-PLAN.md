# Plan 16-01: 数据库迁移 + User 领域扩展

## 目标

为 Phase 16 的所有功能建立数据层基础：
1. 创建 user_insights 表存储记忆 DNA 分析结果
2. 扩展 users 表 settings JSONB 结构（echo_persona, privacy_settings）
3. 扩展 User 领域模型和相关 request/response 类型
4. 创建 user_sessions 表支持活跃会话管理

## 任务清单

### 1. 创建数据库迁移 shared/migrations/007_user_hub.sql

user_insights 表：
- id uuid PK
- user_id uuid, not null, index, FK -> users(id)
- generated_at timestamp, not null
- period_type varchar(20), not null -- weekly | monthly
- knowledge_areas jsonb -- 知识领域分布
- reading_preferences jsonb
- recording_rhythm jsonb
- tag_evolution jsonb
- memory_influence jsonb
- ai_insights jsonb
- created_at / updated_at
- 唯一约束：(user_id, period_type, generated_at)

user_sessions 表（活跃会话管理）：
- id uuid PK
- user_id uuid, not null, index
- device_info varchar(255)
- ip_address inet
- created_at timestamp
- last_active_at timestamp
- is_revoked boolean default false

扩展 users.settings JSONB 结构（不修改表结构，文档化预期字段）：
- echo_persona: string
- privacy_allow_ai_training: boolean
- privacy_enable_emotion_analysis: boolean
- privacy_auto_delete_days: number | null

### 2. 扩展 services/user-service/internal/domain/user.go

新增类型：
- UserInsight struct
- UserSession struct
- EchoPersona type
- PrivacySettings struct
- UpdateProfileRequest
- ChangePasswordRequest
- UpdateEmailRequest
- ExportDataRequest

### 3. 扩展 services/memory-service/internal/domain/memory.go

新增 DNA 相关类型（用于统计查询返回）。

### 4. 验证迁移

- make migrate 或手动执行 SQL
- 确认表结构正确

## 验收标准

- [ ] user_insights 表可通过 GORM 自动迁移创建
- [ ] user_sessions 表结构正确
- [ ] User 领域模型新增类型编译通过
- [ ] Memory 领域模型新增类型编译通过
- [ ] 迁移脚本在现有数据库上可幂等执行
