# Plan 16-05: /profile 页面框架 + 记忆 DNA 可视化

## 目标

1. 实现 /profile 页面整体布局（单列 720px 居中）
2. 用户信息卡片（头像上传、用户名编辑、邮箱展示）
3. Tab 切换（记忆 DNA / AI 人格 / 学习路径 / 数据仪表盘）
4. 记忆 DNA Tab 内容：雷达图 + 统计卡片 + AI 洞察语

## 任务清单

### 1. 安装依赖

npm install recharts react-cropper react-countup

### 2. 扩展 web/lib/api.ts

新增 API 方法：
- getUserDNA(): Promise<UserDNA>
- refreshDNA(): Promise<void>
- getUserStats(): Promise<UserStats>
- updateUsername(username: string): Promise<void>
- uploadAvatar(file: File): Promise<{ avatar_url: string }>

新增类型：UserDNA, UserStats 等

### 3. 创建 /profile 页面框架

布局：max-w-[720px] mx-auto
顶部：用户信息卡片
下方：Tabs 组件（shadcn/ui Tabs）

### 4. 创建 UserProfileCard 组件

头像 80x80px 圆形，点击触发文件选择
用户名可点击切换为 inline 编辑
邮箱小字灰色，只读

### 5. 创建 AvatarUpload 组件

使用 react-cropper 裁剪
支持拖拽上传
预览 + 确认裁剪

### 6. 创建 DNA Radar Chart 组件

使用 recharts RadarChart
6 个维度：技术 / 生活 / 艺术 / 商业 / 科学 / 其他
颜色：amber-500 fill, amber-200 stroke

### 7. 创建 DNA Stat Cards 组件（2x2 网格）

阅读偏好、记录节奏、标签演化、记忆影响力

### 8. 创建 DNA Insight Card 组件

引用卡片样式，左侧 amber 竖线
显示 AI 生成的洞察语

### 9. 处理空状态

记忆数 < 10 时显示引导文案

## 验收标准

- [ ] /profile 页面布局正确，Tab 切换流畅
- [ ] 用户信息卡片可编辑用户名
- [ ] 头像上传组件可裁剪并更新头像
- [ ] DNA 雷达图正确展示 6 个维度
- [ ] 4 个统计卡片数据正确
- [ ] 空状态文案与 16-UI-SPEC.md 一致
