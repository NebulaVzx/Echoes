## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, node border width |
| sm | 8px | Compact element spacing, tooltip padding |
| md | 16px | Default element spacing, card padding (comfortable) |
| lg | 24px | Section padding, graph control bar height |
| xl | 32px | Layout gaps, empty state vertical padding |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

**Exceptions:**
- RightPanel width: 280px (default), resizable 200-400px — Phase 11 established
- Graph canvas: fills remaining viewport height (`calc(100dvh - var(--header-height))`)
- Mobile dock height: 56px + safe-area-inset-bottom — Phase 11 established
- Node touch target: 44px minimum (mobile accessibility)

## Interaction Design

### Desktop Interactions

| Gesture | Target | Action | Feedback |
|---------|--------|--------|----------|
| Hover | Node | Tooltip appears (300ms delay), connected edges highlight | Node enlarges 1.2x, opacity shift |
| Click | Node | Select node, show details in RightPanel | Node gets selection ring, RightPanel slides in (200ms) |
| Double-click | Node | Focus/zoom to node (zoom level 2.0, center on node) | Smooth zoom animation (300ms ease-out) |
| Drag | Canvas background | Pan view | Cursor: grab/grabbing |
| Scroll | Canvas | Zoom in/out (0.5x - 4.0x range) | Zoom centered on cursor position |
| Right-click | Node | Context menu: "探索此记忆" / "查看详情" / "复制链接" | Menu appears at cursor |
| Click | Edge | Highlight edge, show similarity score tooltip | Edge widens temporarily |

### Mobile Interactions

| Gesture | Target | Action | Feedback |
|---------|--------|--------|----------|
| Tap | Node | Select node, push explore page | Haptic feedback (if available) |
| Long press | Node | Show node details modal | Modal slides up from bottom |
| Double tap | Node | Focus/zoom to node | Smooth zoom animation |
| Single finger drag | Canvas | Pan view | — |
| Pinch | Canvas | Zoom in/out | Native pinch gesture |
| Tap | "探索更远" | Load next batch | Button loading state |

### Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `Esc` | Deselect node, close RightPanel |
| `+` / `=` | Zoom in |
| `-` | Zoom out |
| `0` | Reset zoom to 1.0 |
| `f` | Fit graph to viewport |
| `?` | Show keyboard shortcuts help |

### Animation Specs

| Animation | Duration | Easing | Trigger |
|-----------|----------|--------|---------|
| RightPanel slide-in | 200ms | ease-out | Node click |
| RightPanel slide-out | 200ms | ease-out | Deselect / Esc |
| Node selection ring | 150ms | ease-out | Click |
| Zoom transition | 300ms | ease-out | Double-click / button |
| Tooltip fade-in | 150ms | ease-out | Hover (300ms delay) |
| Graph initial layout | 8000ms max | d3-force physics | Data load |
| Highlight fade | 200ms | ease-out | Hover in/out |
| Breadcrumb item enter | 200ms | ease-out | New drill level |

## Accessibility

### WCAG 2.1 AA Requirements

| Requirement | Implementation |
|-------------|----------------|
| Color contrast | All text on graph uses Canvas rendering with contrast ratio >= 4.5:1 against background |
| Focus indicators | Selected node has 2px solid ring + glow; keyboard navigation highlights visible |
| Motion reduction | Respect `prefers-reduced-motion`: disable force simulation animation, instant layout |
| Touch target | Mobile nodes minimum 44px; controls minimum 44x44px |
| Screen reader | Graph has `role="img"` + `aria-label` describing node count and connection summary; individual nodes not traversable (complexity too high) |
| Alternative view | "列表视图" toggle for users who cannot use graph visualization |

### ARIA Labels
