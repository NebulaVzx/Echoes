## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client → Gateway /chat/* | JWT auth required; userID extracted from token |
| Gateway → Memory Service | Internal network; JWT forwarded for auth |
| Gateway → Processor Service | Internal network; no auth needed (internal) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-06 | Elevation of Privilege | Cross-user conversation access | mitigate | All repo queries filter by user_id; handler extracts userID from JWT (not request body) |
| T-06-07 | Information Disclosure | Message content in logs | mitigate | Log only conversation_id and metadata; never log message content |
| T-06-08 | Denial of Service | Unbounded message history fetch | mitigate | GetMessagesByConversation limits to 200 max; ListConversations limits to 100 max |
| T-06-09 | Tampering | Prompt injection via user message | mitigate | User content is in user message role, not system prompt; system prompt is trusted |
| T-06-10 | Information Disclosure | Citations leak other user's memories | mitigate | Citations only include memories retrieved for the current user (user-scoped search) |
| T-06-11 | Denial of Service | LLM call without timeout | mitigate | HTTP client timeout 30s; LLM max_tokens 1000 |
</threat_model>
