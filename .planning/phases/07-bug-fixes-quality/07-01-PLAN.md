## 现有代码关键片段

当前 OAuth state 存储（lines 68-95）:
```go
var (
    oauthStates   = make(map[string]time.Time)
    oauthStateMux sync.Mutex
)

func generateState() string {
    b := make([]byte, 16)
    if _, err := rand.Read(b); err != nil {
        return fmt.Sprintf("%d", time.Now().UnixNano())
    }
    state := hex.EncodeToString(b)
    oauthStateMux.Lock()
    oauthStates[state] = time.Now().Add(10 * time.Minute)
    oauthStateMux.Unlock()
    return state
}

func validateState(state string) bool {
    oauthStateMux.Lock()
    expiry, ok := oauthStates[state]
    delete(oauthStates, state)
    oauthStateMux.Unlock()
    return ok && time.Now().Before(expiry)
}
```

问题：已设置 10 分钟过期时间，但无清理机制，验证后删除仅覆盖成功消费的 state，失败/过期的 state 永远留在 map 中。

    修改 `services/user-service/internal/transport/auth_handler.go`，在现有 OAuth state 存储基础上添加以下机制（per D-01）：

    1. **新增常量**：`oauthStateTTL = 10 * time.Minute`（明确 TTL 时长，与现有 `time.Now().Add(10 * time.Minute)` 一致）

    2. **新增变量**：
       ```go
       var startCleanupOnce sync.Once
       ```

    3. **新增清理函数** `cleanupOAuthStates()`：
       - 使用 `time.NewTicker(5 * time.Minute)` 创建定时器
       - 每次 tick 时：锁定 `oauthStateMux`，遍历 `oauthStates`，删除 `time.Now().After(expiry)` 的条目，解锁
       - 该函数应在单独的 goroutine 中运行，永不返回（for range ticker.C 循环）

    4. **修改 `generateState()`**：在函数开头添加懒启动清理 goroutine：
       ```go
       startCleanupOnce.Do(func() {
           go cleanupOAuthStates()
       })
       ```
       保持原有 state 生成和存储逻辑不变。

    5. **修改 `validateState()`**：将过期判断从 `time.Now().Before(expiry)` 改为显式计算：
       ```go
       valid := ok && time.Now().Before(expiry)
       if !valid {
           // 确保过期/无效的 state 也被删除
           delete(oauthStates, state)
       }
       oauthStateMux.Unlock()
       return valid
       ```
       注意：当前代码在验证时已经 `delete(oauthStates, state)`，这已满足"消费后删除"。但需确保在 `!ok` 或过期时同样删除（当前 `delete` 在 `!ok` 时是无害的 no-op）。

    6. **确保线程安全**：所有对 `oauthStates` 的访问必须通过 `oauthStateMux` 保护。

    关键约束：
    - 不引入 Redis（D-01 决策：单机部署，map+goroutine 足够）
    - 保持现有 `map[string]time.Time` + `sync.Mutex` 结构
    - 清理间隔 5 分钟，TTL 10 分钟
