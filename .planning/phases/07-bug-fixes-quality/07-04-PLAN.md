       先执行 `grep -n "isNewConversation\|buildMessages\|json.Marshal(citations)" services/gateway/internal/chat/service/chat_service.go` 定位相关代码位置。

       当前代码在循环中每次都将系统消息 prepend 到 messages 数组，导致系统消息重复。修复后的逻辑：
       ```go
       func (s *ChatService) buildMessages(query string, memories []domain.SearchResultMemory, history []domain.Message) []map[string]string {
           messages := make([]map[string]string, 0, MaxHistoryMessages+2)

           // 1. System message with RAG context (只插入一次)
           systemContent := s.assembleSystemPrompt(memories)
           messages = append(messages, map[string]string{
               "role":    "system",
               "content": systemContent,
           })

           // 2. Recent history (up to MaxHistoryMessages, filter out system if any)
           // 历史消息按时间正序追加到 system 消息之后
           historyMessages := make([]map[string]string, 0, MaxHistoryMessages)
           count := 0
           for i := len(history) - 1; i >= 0 && count < MaxHistoryMessages; i-- {
               msg := history[i]
               if msg.Role == "system" {
                   continue
               }
               historyMessages = append(historyMessages, map[string]string{
                   "role":    msg.Role,
                   "content": msg.Content,
               })
               count++
           }
           // Reverse to maintain chronological order (oldest first)
           for i := len(historyMessages) - 1; i >= 0; i-- {
               messages = append(messages, historyMessages[i])
           }

           // 3. Current user query
           messages = append(messages, map[string]string{
               "role":    "user",
               "content": query,
           })

           return messages
       }
       ```
       关键变更：
       - 系统消息只在开头插入一次
       - 历史消息先收集到临时数组（倒序遍历），再反转追加（保持时间正序）
       - 不再在每次循环中操作 messages[1:] 和 prepend 系统消息

    2. **修复 WR-02 - 静默 json.Marshal 错误**:
       将 `citationsJSON, _ := json.Marshal(citations)` 改为显式错误处理：

       ```go
       citationsJSON, err := json.Marshal(citations)
       if err != nil {
           s.logger.Error("failed to marshal citations", zap.Error(err), zap.String("conversation_id", conversationID.String()))
           citationsJSON = []byte("[]")
       }
       ```
       注意：`citationsJSON` 变量已在前面声明，这里需要避免重复声明。
