# Phase 17 Context

## 问题诊断

### 当前布局现状

```
┌──────────────────────────────────────────┐
│ Header: Logo + Search + AI + Theme +     │  ← 拥挤，已塞不下更多入口
│         Capsule + Settings + User + Exit │
├──────────────────────────────────────────┤
│                                          │
│    max-w-3xl 窄栏居中                    │  ← 大屏幕上左右大量空白
│    (WarmthCards + CreateForm +           │
│     TagFilter + MemoryList)              │
│                                          │
└──────────────────────────────────────────┘
```

### 核心问题

1. **Header 过载**：已有 AI、主题、时间胶囊、设置、用户名、退出 —— 规划中的星图、探索、情绪、编织等无处安放
2. **空间浪费**：桌面端 1920px 宽屏，主内容只占 768px，左右各空 576px
3. **无全局导航**：每个页面各自为政，新用户找不到功能入口
4. **缺乏层级**：设置页和首页之间缺少"中间层"（个人资料、数据仪表盘）
5. **无快捷方式**：没有 Command Palette、快捷键体系，高级用户效率低

## 改造目标

**从"单栏信息流"升级为"三栏自适应工作台"**

| 维度 | 改造前 | 改造后 |
|------|--------|--------|
| 导航 | Header 按钮堆砌 | 左侧 Sidebar + 底部 Dock |
| 内容区 | max-w-3xl 固定 | 自适应三栏，按场景调整 |
| 空间利用 | 左右空白 | 右侧面板显示上下文 |
| AI 交互 | Chat 侧边栏独立 | 融入全局，支持命令面板 |
| 快捷方式 | 无 | Cmd+K 命令面板 + 快捷键 |

## 设计方案

### 1. 全局布局：三栏自适应

```
桌面端（≥1280px）
┌──────────────────────────────────────────────────────────────┐
│ Header: Logo + 全局搜索 + 用户头像菜单                        │
├─────────┬────────────────────────────────────┬───────────────┤
│         │                                    │               │
│ Sidebar │     主内容区（按场景自适应宽度）    │  Right Panel  │
│ (导航)  │                                    │  (上下文面板)  │
│  200px  │                                    │   280px       │
│         │                                    │               │
└─────────┴────────────────────────────────────┴───────────────┘

平板端（768px-1279px）
┌──────────────────────────────────────────┐
│ Header: Logo + 搜索 + 汉堡菜单 + 用户头像  │
├──────────────────────────────────────────┤
│                                          │
│  主内容区（隐藏 Sidebar 和 Right Panel）  │
│                                          │
└──────────────────────────────────────────┘

移动端（<768px）
┌──────────────────────────────────────────┐
│ Header: Logo + 搜索 + 用户头像             │
├──────────────────────────────────────────┤
│                                          │
│  主内容区                                 │
│                                          │
├──────────────────────────────────────────┤
│  [拾][星][胶][标][我]    Dock 导航        │
└──────────────────────────────────────────┘
```

### 2. Header 精简

**改造前**：Logo + Search + AI按钮 + Theme + Capsule + Settings + Username + Exit
**改造后**：
- 左侧：Logo（点击回首页）
- 中间：全局搜索（扩大，支持 AI 自然语言搜索）
- 右侧：用户头像（点击展开菜单：个人资料、设置、主题、退出）

```
Header
├─ Logo ── 全局搜索 ─────────────── 用户头像 ─┤
                                    └─ 下拉菜单
                                        ├─ 👤 我的画像
                                        ├─ ⚙️ 设置
                                        ├─ 🌙 暗黑/亮色
                                        └─ 🚪 退出
```

### 6. Command Palette（命令面板）

**触发**：Cmd/Ctrl + K

**功能**：
```
搜索记忆...          (直接搜索)
跳转页面             (时间轴/星图/探索/标签...)
创建记忆             (快速弹出创建框)
打开设置             (直接跳设置)
切换主题             (暗黑/亮色)
随机探索             (进入探索模式)
查看画像             (打开个人画像)
```

**交互**：
- 输入 `/` 快速分类（/记忆 /标签 /设置）
- 输入 `>` 执行命令（>导出 >删除）
- 支持 emoji 搜索（输入 🔥 找到热门记忆）

### 7. AI 时代的 UI 特征融入

#### 生成式界面元素
- **动态 Placeholder**：输入框的 placeholder 根据时间/上下文变化
  - 早上："早上好，今天想记录什么？"
  - 深夜："夜深了，还有什么灵感没记下？"
  - 连续记录 7 天后："第 7 天！继续保持 🔥"
- **AI 搜索框**：搜索框内嵌 AI 助手图标，点击切换"语义搜索"和"AI 问答"
- **智能空状态**：空状态文案由 AI 根据用户历史生成（"你的知识库还缺 AI 相关的内容哦"）

#### 流式反馈
- **记忆封面生成**：骨架屏 + 渐进式加载（从模糊到清晰）
- **AI 建议**：打字机效果实时输出
- **向量搜索**：搜索过程中显示"正在检索 1,247 条记忆..."的实时状态
- **文件解析**：进度条 + 已提取字数实时更新

#### 智能密度调节
- **密度设置**：紧凑 / 舒适 / 宽松（用户偏好）
- **紧凑模式**：卡片更小（60px）、间距 8px、显示更多标签
- **舒适模式**：当前默认（卡片 80-120px、间距 16px）
- **宽松模式**：卡片更大（140px+）、间距 24px、更利于阅读

#### 沉浸式探索
- **全屏模式**：星图和探索模式支持 `F` 键全屏
- **手势支持**：移动端左右滑动切换主页面
- **聚焦模式**：记忆详情页按 `F` 隐藏所有导航，只显示内容

### 8. 趣味性与品味

#### 视觉彩蛋
- **里程碑庆祝**：记录达到 100/500/1000 条时，页面有 subtle 的粒子动画（confetti-lite，不打扰）
- **Streak 火焰**：连续记录天数在 Sidebar 用户头像旁显示火焰动画
- **时间胶囊解锁**：全屏渐变遮罩 + 记忆卡片从模糊到清晰的揭示动画
- **暗黑切换**：过渡动画（300ms 渐变，非瞬间切换）

#### 微交互
- **卡片悬停**：微妙的抬升（translateY -2px）+ 阴影加深
- **标签悬停**：颜色从点扩散到整个标签背景
- **星标点击**：弹跳动画（scale 1.2 → 1.0）+ 金色闪光
- **保存成功**：记忆匣图标闪烁 + "已存入" toast 从底部滑出

#### 个性化
- **主题色**：用户可选择强调色（不只是灰度）
  - 预设：石墨灰（默认）、深海蓝、森林绿、珊瑚橙、紫罗兰
- **字体选择**：Inter（默认）、系统默认、等宽（代码爱好者）
- **卡片样式**：简洁（无封面）/ 丰富（有封面+摘要）/ 极简（只标题）

```typescript
// 布局状态

  sidebarCollapsed: boolean      // Sidebar 是否折叠
  rightPanelVisible: boolean     // 右侧面板是否显示

  themeColor: string             // 强调色
  fontFamily: 'inter' | 'system' | 'mono'
}

// 命令面板状态
interface CommandPaletteState {
  isOpen: boolean
  query: string
  results: CommandResult[]
}
```
