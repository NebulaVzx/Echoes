Key configuration:
- `devUrl`: "http://localhost:3000" — points to Next.js dev server

- App title: "拾忆 - Echoes" (Chinese priority)
- Identifier: "com.echoes.desktop"

Note: `beforeBuildCommand` assumes Next.js can do `output: 'export'`. For Phase 11, only `tauri dev` mode needs to work (localhost:3000). Production static export configuration is deferred.

Do NOT run `npm install` in apps/desktop/ — the packages are in this package.json but actual installation should happen when the user is ready to set up the Tauri toolchain. Document this.

**Part B: Create apps/desktop/src-tauri/src/main.rs:**

```rust
// Prevents additional console window on Windows in release, DO NOT REMOVE!!
#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")]

fn main() {
    echoes_desktop_lib::run()
}
```

**Part C: Create apps/desktop/src-tauri/src/lib.rs:**

```rust
// Echoes Desktop — minimal Tauri 2.0 wrapper
// Config: tauri.conf.json
// Dev mode: loads http://localhost:3000 (Next.js dev server)
// Build mode: loads static files from ../../web/out

#[cfg_attr(mobile, tauri::mobile_entry_point)]
pub fn run() {
    tauri::Builder::default()
        .run(tauri::generate_context!())
        .expect("error while running Echoes desktop application");
}
```

**Part D: Create apps/desktop/src-tauri/capabilities/default.json:**

```json
{
  "$schema": "https://raw.githubusercontent.com/nicedoc/tauri/dev/core/tauri-config-schema/schema.json",
  "identifier": "default",
  "description": "Default capability for Echoes desktop",
  "windows": ["main"],
  "permissions": [
    "core:default"
  ]
}
```

**Part E: Create apps/desktop/src-tauri/build.rs:**

```rust
fn main() {
    tauri_build::build()
}
```

This is the absolute minimum Tauri 2.0 project structure:
- `main.rs`: Entry point calling the library's run()
- `lib.rs`: Creates the Tauri app with `tauri::Builder::default().run()`
- `Cargo.toml`: Dependencies on tauri v2
- `capabilities/default.json`: Minimal permissions (core:default)
- `build.rs`: Tauri build script

The total Rust code is ~30 lines — this is intentionally minimal. The real value is the config files and the desktop packaging pathway.

**Important:** Do NOT attempt to compile the Rust code (`cargo build` or `tauri build`). Rust/Cargo may not be installed on this machine (per RESEARCH.md environment availability). The Phase 11 deliverable is the SOURCE CODE only. Document compilation instructions in SUMMARY.
