## Typography

| Role | Size | Weight | Line Height | Tailwind Class |
|------|------|--------|-------------|----------------|
| Body | 14px | 400 (regular) | 1.5 | `text-sm` |
| Label | 12px | 400 (regular) | 1.25 | `text-xs` |
| Heading | 20px | 600 (semibold) | 1.2 | `text-xl font-semibold` |
| Display | 28px | 600 (semibold) | 1.1 | `text-3xl font-semibold` |

**Exactly 2 font weights:** 400 (regular) and 600 (semibold).

**Shadcn preset exception:** shadcn base-nova buttons use `font-medium` (weight 500). This is a shadcn component-level override and is not a design-system token for external use in layout or custom components.

**Font stacks:**
- Sans (body, UI): `Inter, system-ui, -apple-system, sans-serif` — applied via `inter.className` on `<body>`
- Sans (variable, headings): `Geist, sans-serif` — available via `--font-sans` CSS variable

**Chinese text rendering:** Inter and Geist both include Latin/CJK subsets. Chinese characters fall back to system fonts via the `system-ui, -apple-system` chain when Inter lacks the glyph. No dedicated CJK font required at this phase.

**Source:** Derived from `tailwind.config.ts` (`fontFamily.sans`), `app/layout.tsx` (Inter className + Geist variable), and existing component patterns.

## Color

### Default Theme (石墨灰 / Neutral)

| Role | Tokens | Light Value | Dark Value | Usage |
|------|--------|-------------|------------|-------|
| Dominant (60%) | `--background` | #FFFFFF | #0A0A0A | Page background, main content area |
| Secondary (30%) | `--card`, `--secondary`, `--muted`, `--sidebar` | #F7F7F7–#FFFFFF | #0A0A0A–#1A1A1A | Cards, sidebar background, nav, hover states, right panel |
| Accent (10%) | `--primary` | #0A0A0A (near-black) | #FCFCFC (near-white) | See "Accent reserved for" below |
| Destructive | `--destructive` | oklch(0.577 0.245 27.325) | oklch(0.704 0.191 22.216) | Destructive actions only |

**Accent reserved for (neutral default, `--primary`):**
- Primary buttons (variant="default")
- Text links and inline links
- Active/selected navigation item indicator (left accent bar in Sidebar)
- Active sidebar item background highlight
- Focus rings (`--ring`)
- Command Palette highlighted/selected result row
- Mobile Dock active tab indicator dot

**NOT reserved for:** headings, borders, icons (use `--foreground`), card backgrounds (use `--card`), hover states on non-accent elements (use `--muted`/`--secondary`), or any decorative elements.

### Accent Color Presets (Phase 11 feature — user-selectable)

When a user selects an accent color, the CSS variable `--primary` is swapped. The default is 石墨灰 (neutral, shown above).

| Preset | Name | `--primary` Light (approx) | `--primary` Dark (approx) | Tailwind Reference |
|--------|------|---------------------------|--------------------------|--------------------|
| Default | 石墨灰 | oklch(0.205 0 0) / #1A1A1A | oklch(0.985 0 0) / #FCFCFC | neutral |
| Accent 1 | 深海蓝 | oklch(0.546 0.245 262.881) | oklch(0.623 0.214 259.815) | blue |
| Accent 2 | 森林绿 | oklch(0.596 0.145 163.225) | oklch(0.665 0.12 158.18) | emerald/green |
| Accent 3 | 珊瑚橙 | oklch(0.646 0.192 41.116) | oklch(0.704 0.18 48.54) | orange |
| Accent 4 | 紫罗兰 | oklch(0.545 0.238 291.664) | oklch(0.606 0.24 292.685) | violet |

**Accent preset implementation:** A `ThemeColorContext` provider stores the selected accent. A CSS-in-JS or `style` attribute injection swaps `--primary`, `--primary-foreground`, and `--ring` on `:root`. All shadcn components using `bg-primary` / `text-primary-foreground` / `ring` will pick up the change without re-render.

### Theme Transition

All color properties transition over 300ms ease-out when switching dark/light:

```css
*, *::before, *::after {
  transition: background-color 300ms ease-out,
              color 300ms ease-out,
              border-color 300ms ease-out;
}
```

This applies to the theme toggle between dark and light modes. The accent color switch is instant (no transition needed since user explicitly picks it).

**Source:** Colors derived from `app/globals.css` CSS variables (shadcn neutral preset, expanded). Accent presets specified in CONTEXT.md Section 8 (个性化).

## Interaction Patterns

### Global

| Interaction | Implementation |
|-------------|----------------|
| Command Palette trigger | `Cmd+K` / `Ctrl+K` keyboard shortcut, or click Header search |
| Theme toggle | User menu dropdown, or Command Palette `>切换主题` |
| Accent color switch | Settings page color picker, instant apply |
| Density toggle | Settings page, instant apply via CSS custom properties |

### Sidebar

| Interaction | Implementation |
|-------------|----------------|
| Navigate | Click item to navigate; active item highlighted with left accent bar |
| Collapse | Click chevron toggle at sidebar bottom; animate width 200px <-> 48px (200ms) |
| Collapsed hover | Tooltip shows item label (shadcn tooltip) |
| New feature badge | Glowing dot + ✨ emoji badge on "星图", "探索", "情绪", "编织", "画像" |

### Right Panel

| Interaction | Implementation |
|-------------|----------------|
| Toggle visibility | Click chevron toggle in panel header; slide in/out (200ms) |
| Resize width | Drag left edge of panel; clamp 200px–400px; persist to localStorage |
| Adaptive content | Panel widgets switch based on `usePathname()` of current page |

### Mobile Dock

| Interaction | Implementation |
|-------------|----------------|
| Tab switch | Tap icon to navigate; active tab with accent underline indicator |
| Tab labels | Icon + short label below (拾/星/胶/标/我) |
| Visibility | Fixed at bottom; `<768px` only; safe-area inset via `env(safe-area-inset-bottom)` |

### Memory Cards (existing, enhanced in Phase 11)

| Interaction | Implementation |
|-------------|----------------|
| Card hover | `translateY(-2px)` + shadow deepen (200ms ease-out, Framer Motion) |
| Tag hover | Color dot expands to fill tag background (200ms) |
| Star click | `scale(1.2 -> 1.0)` bounce + gold flash (300ms spring) |
| Save success | Memory box icon pulse + toast slide-up from bottom (200ms) |

### Celebrations

| Event | Animation |
|-------|-----------|
| 100/500/1000 memory milestone | Confetti-lite: small particles float up from bottom, ~500ms, non-blocking |
| Streak continues | Flame icon pulse + glow (subtle, 200ms loop while streak active) |
| Time capsule unlock | Full-screen gradient overlay fades in, then memory card reveals from blur-to-sharp (500ms) |
| Theme switch | 300ms cross-fade on all color properties |
