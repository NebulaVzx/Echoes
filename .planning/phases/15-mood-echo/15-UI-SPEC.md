# Phase 15 — 情绪与回响 (Mood & Echo) — UI Design Contract

> Visual and interaction contract for Phase 15 frontend. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> This contract covers the Mood Calendar page (`/mood`), Daily Echo extensions, and Echo Style preferences.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn/ui v3 |
| Preset | Notion-like minimal, OKLCH color variables |
| Component library | Radix UI (via shadcn v3) |
| Icon library | lucide-react |
| Font | Inter (body), system-ui fallback |
| Animation library | Framer Motion |

**Alignment with existing project:**
- Uses existing OKLCH CSS variables from `web/app/globals.css` (NOT hsl())
- Dark mode via `dark:` prefix and `.dark` class on `<html>`
- Three-column AppShell layout (Sidebar + Main + RightPanel) from Phase 11
- Tailwind v3 with custom spacing/content tokens in `tailwind.config.ts`

## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, heatmap cell gap |
| sm | 8px | Compact element spacing, tooltip padding |
| md | 16px | Default element spacing, card padding |
| lg | 24px | Section padding, page header margin |
| xl | 32px | Layout gaps, major section breaks |
| 2xl | 48px | Page-level top padding |
| 3xl | 64px | Hero section spacing |

**Exceptions:**
- Heatmap cell size: 10px (desktop), 8px (mobile) — component dimension, not spacing token
- Heatmap cell gap: 2px (all breakpoints) — **visual density exception** (GitHub-style tight grid, smaller than spacing scale for data density)
- Touch targets for heatmap day cells: minimum 32px on mobile (invisible tap area beyond the visual cell)

## Color

### Base Palette (from existing design system)

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--background)` oklch(1 0 0) / oklch(0.145 0 0) dark | Page background, surfaces |
| Secondary (30%) | `var(--card)` oklch(1 0 0) / oklch(0.205 0 0) dark | Cards, sidebar, panels |
| Accent (10%) | `var(--primary)` oklch(0.205 0 0) / oklch(0.922 0 0) dark | Interactive elements, active states |
| Destructive | `var(--destructive)` oklch(0.577 0.245 27.325) | Error states, destructive actions |

### Mood Heatmap Colors (Phase 15 specific)

The heatmap uses a diverging color scale mapped to sentiment scores (-10 to +10):

| Sentiment | Score Range | Light Mode | Dark Mode |
|-----------|-------------|------------|-----------|
| Strongly Positive | +8 to +10 | `#216e39` (deep green) | `#39d353` (bright green) |
| Positive | +5 to +7 | `#30a14e` (green) | `#2ea043` (green) |
| Mildly Positive | +2 to +4 | `#56d364` (light green) | `#56d364` (light green) |
| Neutral | -1 to +1 | `#ebedf0` (gray) | `#161b22` (dark gray) |
| Mildly Negative | -4 to -2 | `#f85149` (light red) | `#f85149` (light red) |
| Negative | -7 to -5 | `#cf222e` (red) | `#da3633` (red) |
| Strongly Negative | -10 to -8 | `#82071e` (deep red) | `#ff7b72` (bright red) |

**Color rules:**
- No data (no memories that day): `#ebedf0` light / `#21262d` dark — slightly darker than neutral
- Hover state: add a 2px ring using `var(--ring)` color
- Selected day: 2px solid `var(--primary)` ring

**Accent reserved for:**
- Selected view tab (Year/Month/Theme)
- Active echo style in selector
- "Generate Echo" CTA button
- Current day indicator in heatmap

## Component Specifications

### 1. MoodCalendar

**Purpose:** GitHub contribution graph-style heatmap showing daily sentiment scores.

**Props:**
```typescript
interface MoodCalendarProps {
  data: MoodDayData[]
  view: 'year' | 'month' | 'theme'
  year: number
  month?: number // for month view
  onDayClick?: (date: string, data: MoodDayData) => void
  onDayHover?: (date: string, data: MoodDayData | null) => void
}

interface MoodDayData {
  date: string // ISO date
  score: number // -10 to +10, or null for no data
  memoryCount: number
  dominantSentiment: 'positive' | 'neutral' | 'negative'
}
```

**Layout:**
- **Year view (desktop):** 53 columns (weeks) x 7 rows (days), left-to-right, top-to-bottom
  - Column gap: 3px, Row gap: 3px
  - Cell size: 10px x 10px
  - Left margin: 28px for day-of-week labels (Mon, Wed, Fri)
  - Top margin: 20px for month labels (Jan, Feb, Mar...)
  - Container max-width: 900px, centered
- **Month view (mobile default):** 7 columns x 5-6 rows (calendar grid)
  - Cell size: flex-1, minimum 32px height for touch
  - Cell gap: 4px
  - Shows day number inside cell (12px font)
- **Theme view:** Grouped by sentiment clusters, not chronological

**Cell rendering:**
- Each cell is a `<button>` for accessibility
- Background color from mood color scale (see Color section)
- Border-radius: 2px (square-ish like GitHub)
- No border by default; 2px `var(--ring)` ring on hover
- Focus visible: 2px solid `var(--primary)` ring

**Animation:**
- Cells fade in with stagger: `delay = (weekIndex * 7 + dayIndex) * 8ms`
- Framer Motion: `initial={{ opacity: 0, scale: 0.8 }}`, `animate={{ opacity: 1, scale: 1 }}`
- Duration: 200ms, ease-out

**Responsive:**
- Desktop (>=1280px): Full year view, all 53 weeks visible
- Tablet (768-1279px): Year view with smaller cells (8px)
- Mobile (<768px): Month view by default, swipe to navigate months
- Mobile year view: Accessible via view toggle, shows 3 months at a time

### 4. EchoCard (DailyReview Extension)

**Purpose:** Extends existing `DailyReviewCard` with AI-generated echo message.

**Props:**
```typescript
interface EchoCardProps {
  // Inherits from DailyReviewData
  today_count: number
  top_tags: string[]
  worth_reviewing?: Memory
  // New Phase 15 fields
  echo_message?: string
  echo_style?: 'warm' | 'humorous' | 'concise' | 'poetic'
  onGenerateEcho?: () => void
  onStyleChange?: (style: string) => void
}
```

**States:**

**Collapsed (default):**
- Same as existing DailyReviewCard
- Header: Sparkles icon + "今日拾忆" + ChevronDown
- Height: ~44px

**Expanded:**
- Existing content (today count, tags, worth reviewing)
- **New: Echo section** (below existing content, separated by `Separator`)
  - Echo style selector row (see EchoStyleSelector)
  - Echo message card:
    - Background: `var(--muted)` with 50% opacity
    - Border-radius: 8px
    - Padding: 16px
    - Text: 14px, line-height 1.6, italic style
    - Quote mark decoration: large " character in `var(--muted-foreground)` at top-left
  - "重新生成" button (ghost variant, small) if echo exists
  - Loading state: Skeleton lines (3 lines, pulsing) while generating

**Animation:**
- Expand/collapse: Framer Motion `AnimatePresence` with `height: auto`
- Duration: 250ms, ease-out
- Echo text reveal: fade-in + slide-up, 300ms, stagger 50ms per paragraph

**LocalStorage persistence:**
- `daily_review_collapsed` — existing key, reused
- `echo_style_preference` — new key, stores selected style

## Animation Specifications (Framer Motion)

### Page Load

```typescript
// Calendar container
initial={{ opacity: 0, y: 20 }}
animate={{ opacity: 1, y: 0 }}
transition={{ duration: 0.3, ease: "easeOut" }}

// Calendar cells (staggered)
initial={{ opacity: 0, scale: 0.8 }}
animate={{ opacity: 1, scale: 1 }}
transition={{ duration: 0.2, delay: index * 0.008 }}
```

### View Switch

```typescript
// Fade out old view, fade in new
exit={{ opacity: 0 }}
initial={{ opacity: 0 }}
animate={{ opacity: 1 }}
transition={{ duration: 0.2 }}
```

### Echo Text Reveal

```typescript
// Paragraph by paragraph
initial={{ opacity: 0, y: 8 }}
animate={{ opacity: 1, y: 0 }}
transition={{ duration: 0.3, delay: paragraphIndex * 0.05 }}
```

### Day Detail Panel

```typescript
// Desktop: slide down from calendar
initial={{ opacity: 0, height: 0 }}
animate={{ opacity: 1, height: "auto" }}
transition={{ duration: 0.25, ease: "easeOut" }}

// Mobile: bottom sheet
initial={{ y: "100%" }}
animate={{ y: 0 }}
transition={{ duration: 0.3, ease: "easeOut" }}
```

### Stats Counting

```typescript
// Number animation from 0 to target
const count = useMotionValue(0)
const rounded = useTransform(count, Math.round)
useEffect(() => {
  animate(count, targetValue, { duration: 0.8, ease: "easeOut" })
}, [targetValue])
```

## Accessibility

- Heatmap cells are `<button>` elements with `aria-label`
- Each cell label: "{date}: {sentiment}情绪, {count}条记忆"
- Color is not the only indicator: cells with data have `aria-pressed` when selected
- Tooltip content is readable by screen readers
- EchoCard expand/collapse uses `aria-expanded`
- Style selector uses radio group pattern (`role="radiogroup"`)
- Reduced motion: respect `prefers-reduced-motion`, disable stagger animations
