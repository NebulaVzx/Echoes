    func (s *MemoryService) GetStreak(ctx context.Context, userID uuid.UUID) (currentStreak int, longestStreak int, err error) {
      // Query all memory creation dates for user, ordered desc
      // Group by DATE(created_at) to get unique days
      // Calculate current streak: count consecutive days from today backward
      // Allow 1-day gap (grace period)
      // Longest streak: max consecutive run in history
    }

    The grace-based logic:
    1. Query distinct dates with memories (excluding sealed)
    2. Starting from most recent date:
       - If gap <= 1 day, streak continues

    3. Return current streak count and longest streak count
