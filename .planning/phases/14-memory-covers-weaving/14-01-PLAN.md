per D-02-02, D-02-03, D-02-04, D-02-05, D-02-06, D-02-07:
- `process_message` 流程：
  1. 提取 fields: memory_id, content_type, content, link_url, link_title, file_name, tags
  2. 根据 content_type 选择封面生成策略：
     - "text": 提取标题（前30字）+ 内容前200字 → 生成英文 prompt → DALL-E 3
     - "link": 先尝试抓取 og:image（复用 LinkScraper 或 httpx 直接请求），成功则下载图片；失败则降级为 link_title + link_summary 文本生成
     - "file": 提取 text_content 首段文字 → 同 text 类型生成
  3. 调用 DALL-E 3（b64_json 格式）生成 1024x1024
  4. DALL-E 3 失败时（RateLimitError, APIError, 无 API key）降级 Pollinations.AI
  5. 全部失败时生成 fallback cover（Pillow 纯色背景 + 首字母图标，颜色由首标签 MD5 hash 计算 HSL）
  6. Pillow ImageOps.fit 裁剪为 400x300 (4:3)，JPEG quality=90
  7. MinIO put_object 上传到 echoes-files bucket，路径 `covers/{user_id}/{memory_id}.jpg`
  8. 通过 memory_client.update_task_status 回写 cover_url（task_type="cover:generate"，result={"cover_url": url}）

- `generate_cover_image(prompt: str, api_key: str = None) -> Image.Image` — DALL-E 3 调用，返回 PIL Image

- `crop_cover(image: Image.Image) -> bytes` — ImageOps.fit 到 400x300，JPEG 编码

```go
func (q *RedisTaskQueue) PublishCoverGenerate(ctx context.Context, memoryID uuid.UUID, contentType string, content string, linkURL string, linkTitle string, tags []string, llmConfig map[string]interface{}) error {
    fields := map[string]interface{}{
        "memory_id":    memoryID.String(),
        "content_type": contentType,
        "content":      content,
    }
    if linkURL != "" {
        fields["link_url"] = linkURL
    }
    if linkTitle != "" {
        fields["link_title"] = linkTitle
    }
    if len(tags) > 0 {
        fields["tags"] = strings.Join(tags, ",")
    }
    mergeLLMConfig(fields, llmConfig)
    return q.PublishTask(ctx, "cover:generate", fields)
}
```

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14-01 | Spoofing | DALL-E API call | mitigate | Use HTTPS only; API key from env var, never logged |
| T-14-02 | Tampering | Prompt injection | mitigate | Extract only title+200 chars from user content; no user-controlled prompt per RESEARCH.md |
| T-14-03 | Information Disclosure | b64_json in memory | accept | Image data is transient (decoded immediately, not stored in process memory long-term) |
| T-14-04 | Denial of Service | Excessive DALL-E cost | mitigate | Async queue naturally throttles; Gateway rate limiting exists; Pollinations fallback for dev |
| T-14-05 | Elevation | MinIO path traversal | mitigate | Object path uses UUIDs: `covers/{user_id}/{memory_id}.jpg`; no user-controlled path segments |
| T-14-06 | Spoofing | Pollinations.AI fallback | accept | Dev-only fallback; no sensitive data sent (only English prompt) |
