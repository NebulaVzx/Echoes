# Phase 17 Context

## 目标

探索 AI 驱动的跨领域联想（记忆桥梁），为用户创造"Aha!"时刻。

## 范围

### P2 — 记忆桥梁（Memory Bridge）
- 后台任务：发现"远距离相似对"（相似度 0.60-0.75，不同标签，时间跨度 > 30 天）
- LLM 验证并生成"桥梁说明"
- "今日发现"模块展示 1-2 条
- 用户反馈（有用/不相关）优化质量

## 技术约束
- 记忆桥梁计算成本高，作为"彩蛋功能"或预留
- 复用现有 Echoes API 和向量搜索能力

## 验收标准
- 桥梁发现让用户产生"Aha!"时刻
- 用户反馈机制有效优化推荐质量

---

## 跨平台兼容性考虑

### 记忆桥梁的展示统一

记忆桥梁是后台计算 + 前端展示，三端共享：
- "今日发现"卡片在首页展示，三端 UI 一致
- 用户反馈（有用/不相关）同步到云端，影响后续推荐质量

### 不在本 Phase 做的事

- ❌ 记忆桥梁的实时计算 —— 计算成本高，作为预留/彩蛋功能
- ❌ 跨用户桥梁发现 —— 涉及隐私，需要更充分的设计
