       export default defineConfig({
         testDir: './e2e',
         fullyParallel: true,
         forbidOnly: !!process.env.CI,
         retries: process.env.CI ? 2 : 0,
         workers: process.env.CI ? 1 : undefined,
         reporter: 'list',
         use: {
           baseURL: 'http://localhost:3000',
           trace: 'on-first-retry',
           screenshot: 'only-on-failure',
         },
         projects: [
           { name: 'setup', testMatch: /.*\.setup\.ts/ },
           {
             name: 'chromium',
             use: {
               ...devices['Desktop Chrome'],
               storageState: 'playwright/.auth/user.json',
             },
             dependencies: ['setup'],
           },

           command: 'cd .. && docker-compose up -d && sleep 30',
           url: 'http://localhost:3000',
           reuseExistingServer: !process.env.CI,
           timeout: 120000,
         },
       })
       ```
       Note: The webServer command starts the full docker-compose stack. The 30s sleep gives services time to initialize. In CI, reuseExistingServer should be false so it starts fresh.

       import { test as setup, expect } from '@playwright/test'

       const authFile = 'playwright/.auth/user.json'

       setup('authenticate', async ({ page }) => {
         // Generate unique test user to avoid conflicts
         const timestamp = Date.now()
         const email = `test_${timestamp}@example.com`
         const password = 'TestPassword123!'
         const username = `testuser_${timestamp}`

         // 1. Register
         await page.goto('/register')
         await page.getByLabel(/邮箱|Email/i).fill(email)
         await page.getByLabel(/密码|Password/i).fill(password)
         await page.getByLabel(/用户名|Username/i).fill(username)
         await page.getByRole('button', { name: /注册|Register/i }).click()

         // 2. Wait for redirect to home (auto-login after registration)
         await page.waitForURL('/')

         // 3. Verify we're logged in
         await expect(page.getByText(/时间轴|Timeline/i)).toBeVisible()

         // 4. Save auth state
         await page.context().storageState({ path: authFile })
       })
       ```
       Note: The selectors use regex to match Chinese or English labels. Adjust based on actual page content.
