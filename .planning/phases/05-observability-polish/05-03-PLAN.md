## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client -> Gateway | Trace ID generated here; must not be forged to impersonate |
| Gateway -> Downstream | Trace headers cross internal network |
| Redis Stream | traceparent stored in message fields |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-07 | Spoofing | Forged traceparent header | mitigate | OTel W3C propagator validates traceparent format. Invalid format creates new root span. |
| T-05-08 | Information Disclosure | traceparent in Redis Stream | accept | traceparent contains only trace_id and span_id (random 16-byte hex). No PII. |
| T-05-09 | Denial of Service | Large trace context in Redis | accept | traceparent is ~55 bytes. Negligible overhead. |
</threat_model>
