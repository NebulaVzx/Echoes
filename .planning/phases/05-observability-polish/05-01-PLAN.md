## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client -> Gateway | Untrusted HTTP input crosses here |
| Gateway -> Downstream | Internal network, but trace headers must be validated |
| /metrics endpoint | Publicly exposed metrics — must not leak sensitive data |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Information Disclosure | /metrics endpoint | mitigate | Metrics contain only HTTP-level data (no user_id, no PII). Counter/Histogram labels are limited to service/method/path/status per D-06. |
| T-05-02 | Denial of Service | /metrics endpoint scraping | accept | Low risk — /metrics is lightweight text output. Prometheus scrape interval is 15s. |
| T-05-03 | Tampering | Trace context propagation | mitigate | OTel W3C propagator validates traceparent format. Invalid traceparent is silently ignored, span created as root. |
| T-05-04 | Information Disclosure | Zap logs | mitigate | Logs contain path/method/status but NOT request body, user email, or JWT tokens. Duration_ms does not reveal timing attack vectors (coarse millisecond precision). |
</threat_model>
