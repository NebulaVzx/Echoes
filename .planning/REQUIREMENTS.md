# 需求规格 (v1.2) — 规划中

## 0. 设计原则

- **陪伴感 > 功能性**：每一个功能都要让用户感到"被理解"
- **不打扰**：所有 AI 功能默认关闭或轻柔提示，用户主动选择才展开
- **持久化价值**：生成的内容要能成为用户长期回看的资产
- **视觉克制**：延续 Notion-like 极简，新功能用 subtle 的方式融入

---

## 1. AI 陪伴建议 (P0)

### 1.1 核心机制

- **FEAT-01** 保存记忆后，系统异步调用 LLM 生成"AI 建议"
- **FEAT-02** 建议根据内容类型（text/link）采用不同策略
- **FEAT-03** 建议持久化到数据库，与记忆关联
- **FEAT-04** 用户在创建表单可选择开启/关闭 AI 建议（默认关闭，状态记住）
- **FEAT-05** 建议生成失败时不阻塞保存流程，静默降级

### 1.2 文字内容建议策略

| 触发条件 | 建议类型 | 示例 |
|---------|---------|------|
| 检测到负面情绪词汇 | 情绪支持 | "今天很辛苦呢，要不要顺便记一件值得感恩的小事？" |
| 内容以问号结尾或含"怎么办" | 思考引导 | "这个问题很有意思，一个可能的思考角度是..." |
| 含学习相关词汇（"学会了","笔记"） | 知识拓展 | "你在学习这个领域！之前记的《xxx》可能有关联" |
| 含灵感/创意词汇（"idea","突然想到"） | 灵感催化 | "这个灵感很棒！要不要设一个时间胶囊，一周后回访？" |
| 平淡日常记录 | 温和增强 | "如果配上今天的天气或位置，以后回看会更有趣" |

### 1.3 链接内容建议策略

| 触发条件 | 建议类型 | 示例 |
|---------|---------|------|
| 技术类文章 | 知识关联 | "这篇讲 React Server Components，和你之前的 3 篇 React 笔记可以组成专题" |
| 新闻/资讯 | 背景关联 | "这条涉及 AI 监管，和你之前存的《欧盟AI法案》有关联" |
| 教程/课程 | 行动建议 | "这个教程预计需要 2 小时，建议设为中优先级周末再看" |
| 设计/灵感 | 趋势发现 | "这个风格和上周存的 Dribbble 作品很像，可能是一个趋势" |

### 1.4 建议展示

- **FEAT-06** 记忆卡片上显示 AI 建议图标（✨），hover 展开建议内容
- **FEAT-07** 记忆详情页底部展示完整建议，带快捷操作（「采纳」「不用了」「展开说」）
- **FEAT-08** 用户点击「不用了」后，系统记录偏好，减少同类建议

## 2. 标签重生 (P1)

### 2.1 标签过滤器

- **FEAT-09** 时间轴页面顶部增加横向标签栏，显示最常用的 8-10 个标签
- **FEAT-10** 点击标签过滤时间轴（单选），再次点击取消过滤
- **FEAT-11** 支持多标签过滤（AND 逻辑），显示已选标签和「清除全部」按钮

### 2.2 标签管理页

- **FEAT-12** 新增 `/tags` 页面，展示所有标签
- **FEAT-13** 标签云视图：按使用频率调整字体大小
- **FEAT-14** 标签卡片：显示名称、记忆数量、最近更新时间、相关标签 TOP 3
- **FEAT-15** 标签合并：AI 检测相似标签（如 "react" / "React"），建议合并
- **FEAT-16** 标签颜色：每个标签可从预设柔和调色板选色，在时间轴中显示

### 2.3 标签关联发现

- **FEAT-17** 记忆详情页底部显示「相关标签」（基于语义相似度）
- **FEAT-18** 标签管理页显示标签之间的关系网（轻量版）

## 3. 记忆的温度 (P1)

### 3.1 记忆 Streaks

- **FEAT-19** 记录用户连续保存记忆的天数
- **FEAT-20** 创建记忆表单下方显示 streak 状态（今天已保存 / 连续 N 天）
- **FEAT-21** 连续 7/30/100 天在个人资料页显示 subtle 徽章

### 3.2 那年今日（Serendipity）

- **FEAT-22** 每天首次打开首页，时间轴顶部插入「那年今日」卡片
- **FEAT-23** 优先选"一年前的今天"，没有则选"随机高价值旧记忆"
- **FEAT-24** 卡片展示旧记忆内容，底部显示「从那以后，你还保存了 N 条相关记忆」
- **FEAT-25** 用户可点击「不想再看到这条」或「收藏这条回忆」

### 3.3 时间胶囊

- **FEAT-26** 保存记忆时可选「封印」：7天 / 30天 / 100天 / 自定义日期
- **FEAT-27** 被封印的记忆不显示在时间轴，有专门的「时间胶囊」入口
- **FEAT-28** 到期时首页顶部显示「⏳ 一段被封印的记忆已解锁」仪式卡片

### 3.4 每日回顾

- **FEAT-29** 首页时间轴顶部可折叠的「今日拾忆」卡片
- **FEAT-30** 展示今日保存数量、主题标签、一条值得回顾的旧记忆
- **FEAT-31** 无新记忆时显示鼓励文案「今天也要记得拾起些什么 ✨」
